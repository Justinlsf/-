# 一、项目背景与目标 
## 1.1 项目背景 
当前电商行业获客成本持续攀升，粗放式运营已无法支撑平台长期增长，精细化用户运营成为提升平台营收、降低用户流失的核心抓手。多数电商平台面临「用户画像模糊、价值分层不清晰、运营策略无差别、资源投入 ROI 低」的痛点，无法精准定位高价值用户，也无法针对性解决用户流失问题。传统RFM模型有两大局限：无法识别“高潜观望者”以及忽略购买力背景差异。传统RFM模型只看到了消费行为而忽略了浏览行为和用户画像。
本项目基于电商平台用户全维度行为数据，完成用户全景画像搭建、用户价值分层与行为规律挖掘，为平台精细化运营提供数据支撑与可落地的策略建议。
## 1.2 项目核心目标 
完成数据清洗与预处理，保障分析数据的准确性与有效性；
搭建平台用户全景画像，明确核心用户群体的人口属性、地域、兴趣与品类偏好特征；
挖掘影响用户总消费的核心指标，定位平台 GMV 增长的核心抓手；
基于 RFM 经典模型完成用户价值分层；
解决电商运营的核心痛点：有效的营销预算应该投给谁？哪些用户值得重点维护？哪些用户正在流失需要挽回？
## 1.3 数据说明 
数据来源：公开电商平台用户行为与属性数据集
数据规模：1000 条用户样本，15 个特征字段，覆盖用户属性、行为特征、消费价值三大维度
核心字段分类
- 用户属性：用户 ID、性别、年龄、地域、兴趣标签
- 行为特征：上次登录距今天数、网站停留时长、浏览页面数、是否订阅邮件
- 消费特征：购买频率、平均订单价值、总消费额、产品品类偏好

用户属性概述：
- 1. User_ID：每个用户的唯一标识符，便于跟踪和分析。
- 2. Age：用户的年龄，提供对人口偏好的见解。
- 3. Gender：用户的性别，实现针对不同性别的建议和目标。
- 4. Location：用户的位置分为郊区、农村或城市地区，影响偏好和购物习惯。
- 5. Income：用户的收入水平，表明购买力和可负担性。
- 6. Interests：用户的兴趣，如体育、时尚、技术等，指导内容和产品推荐。
- 7. Last_Login_Days_Ago：自用户上次登录以来的天数，反映参与频率。
- 8. Purchase_Frequence：用户进行购买的频率，表明购物习惯和忠诚度。
- 9. Average_Order_Value：用户下订单的平均值，对定价和促销策略至关重要。
- 10. Total_Spending：用户花费的总金额，表示生命周期价值和购买行为。
- 11. Product_Category_Preference：用户对特定产品类别的偏好，提供个性化建议。
- 12. Time_Spent_on_Site_Minutes：用户在电子商务平台上花费的时间，表示参与度。
- 13. Pages_Viewed：用户在访问期间查看的页面数，反映浏览活动和兴趣。
- 14. Newsletter_Subscription：指示用户是否订阅了时事通讯，从而启用有针对性的营销活动。
